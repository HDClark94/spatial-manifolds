## Summary

Spatial firing in the medial entorhinal cortex (MEC) is not fixed to the external world: on a virtual track, a neuron's firing can be anchored to the task reference frame on some trials and not others, and anchoring predicts whether mice find a reward that can only be located by path integration. Using four-shank Neuropixels recordings in 8 mice, with cell identity assigned in an open-field session, we show that anchoring is a population state, correlated across simultaneously recorded neurons and organised into blocks of tens of trials. Every cell class follows it, grid cells and putative interneurons about twice as strongly as non-grid spatial cells, yet synaptically connected pairs share it no more than matched unconnected pairs, so it is not propagated through the local circuit. The state tracks pupil-indexed task engagement. In other structures, labels track performance largely by recording behaviour; where hits and misses run alike, only MEC, and more weakly the subicular complex, still predicts it. The state is accompanied by frequency-specific changes in the local field potential, and the grid attractor remains intact when anchoring is lost. A model in which engagement gates a landmark correction predicts, as observed, that fast gamma tracks positional error. We suggest that the state sets not whether a grid code exists but whether it is corrected to the task.

## Introduction

Grid cells in the medial entorhinal cortex (MEC) are thought to provide a metric for space that supports navigation and memory. A standard view is that this metric is continuously available and stably anchored to the external world. Several observations challenge that view. On circular tracks, grid firing remains periodic but is no longer anchored to the environment, so that it is informative about distance travelled rather than position (Jacob et al., 2019). Populations of MEC neurons can spontaneously remap between representations within a session (Low et al., 2021). During a virtual-track location memory task, grid firing switches between a task-anchored mode, in which fields recur at the same track positions, and a task-independent mode, in which they do not, and this switching is associated with behaviour: anchoring predicts successful localisation of a reward zone when the animal must path-integrate to find it, but not when a visual cue marks it (Clark and Nolan, 2024).

That dissociation makes the switching itself worth explaining. If anchoring determines whether an internal position estimate is usable, then whatever controls anchoring controls when the grid code contributes to behaviour. Two broad accounts are available. Under the first, anchoring is set within the entorhinal circuit — by the balance of visual and self-motion input to the grid network, or by interactions among its own neurons, in which case the cells that share an anchoring state should be those that are connected to one another. Under the second, anchoring reflects a variable that is not entorhinal at all, with the circuit responding to a signal generated elsewhere, in which case shared anchoring should track what a cell is rather than what it is wired to, and the same signal should be legible outside MEC.

Distinguishing these accounts requires three things that have not previously been available together: simultaneous recordings of enough neurons to define a population state trial by trial, independent assignment of cell identity so that the categories cannot be shaped by the dynamics under study, and recordings that extend beyond MEC. We obtained these using four-shank Neuropixels 2.0 probes targeted to span the mediolateral extent of MEC, with the same neurons recorded in an open arena on the same day, and with the probe shanks also sampling the pre-, para- and postsubicular complex, visual cortex, and in some animals cerebellum.

We show here that anchoring to the task reference frame is a population-level state that every entorhinal cell class follows, but that grid cells and putative interneurons follow about twice as strongly as spatial cells without grid structure. These two classes are synaptically coupled, but their synaptic coupling does not account for their shared anchoring, which is more consistent with a common input than with propagation through the local circuit. The state tracks pupil-indexed task engagement. And MEC stands out among the structures recorded alongside it: their labels also track performance, but largely by recording the animal's behaviour, whereas the entorhinal state predicts performance from a stretch of track where behaviour does not differ.

## Results

We recorded from four-shank Neuropixels 2.0 probes targeted to sample the mediolateral extent of the MEC, in mice exploring an open arena and then performing a location memory task on a virtual linear track (Figure 1A–C). Mice were trained for 26.6 ± 6.3 days (range 19–41) before recording (Figure 1D). On cued trials the reward zone was marked by a visual cue; on uncued trials the cue was absent and the zone could only be localised efficiently by path integration. Cell identity was assigned from the open-field session: neurons with grid firing fields in the arena ([n]/[n]) typically showed repeating localised firing on the track, whereas neurons with non-grid spatial firing in the arena ([n]/[n]) more often showed ramping profiles (Figure 1E). Across the dataset we analysed 6,438 MEC neurons from 64 sessions in 8 mice, after excluding units whose refractory-period violations rule out a single neural source (ISI violation ratio above 10; STAR Methods).

### Anchoring to the task reference frame is a property of the population

A cell whose firing is anchored on some trials and not others could be switching independently of its neighbours, in which case anchoring is a property of single neurons, or it could be switching together with them, in which case anchoring is a property of the population. These possibilities make different predictions for simultaneously recorded cells: under the first, trial-by-trial anchoring labels should be uncorrelated across cells; under the second, they should be correlated, and the correlation should exceed what is expected from each cell's overall tendency to be anchored.

To distinguish them we classified each trial of each cell as anchored or non-anchored by comparing that trial's rate map against the cell's own circularly shifted null (see Methods). We then took the first principal component of the resulting cell × trial label matrix and compared it against a circular-shift null that preserves each cell's anchored fraction, so that a cell which is anchored on most trials cannot generate apparent population structure on its own. The first principal component exceeded this null by approximately twofold (Figure 1F). Anchoring was organised in time as well as across cells: blocks of tens of trials shared a state, and the population crossed between states over approximately three trials (Figure 1G). We refer to the per-trial fraction of anchored cells as the population anchoring state.

To ask whether this state is behaviourally relevant we compared stopping outcomes between anchored and non-anchored trials. Mice were more likely to stop in the reward zone on anchored trials, and the advantage was larger on uncued trials, where the zone can only be localised by path integration, than on cued trials, where a visual landmark is available. Quantified per session as the difference between the uncued and cued anchoring benefit, which we refer to as the Anchoring Dependence Index, the effect was positive (+0.112, p = 0.002, 28 sessions), and it survived matching running speed between states (+0.149, p = 0.007, 23 sessions; Figure S4). This reproduces, at the level of a population state, the selective association between anchoring and path integration-dependent performance previously reported for individual grid cells (Clark and Nolan, 2024).

Together, these data indicate that anchoring to the task reference frame is a coordinated state of the recorded population rather than an independent property of single neurons, and that it matters most for behaviour when the animal must rely on an internal estimate of position.

### The anchoring state predicts performance from where behaviour does not differ, most clearly in MEC

If anchoring were a global variable rather than an entorhinal one, it should be legible in the other structures our shanks pass through: visual cortex, the subicular complex and, in some animals, cerebellum. Two things make this harder to ask than it appears. Scoring other structures against the MEC axis can only measure how much they resemble MEC, so each structure built its own state from its own cells. And a structure's labels can predict performance for a reason that has nothing to do with an internal state. The labels compare rate maps over the whole track, and on a miss the animal runs differently through the reward zone: misses run faster than hits there (uncued +12.7 cm/s, cued +5.8 cm/s, more so on uncued trials, p = 2 × 10⁻⁸; Figure 2A, B). A cell whose firing follows running speed, or the stopping that defines a hit, changes its map on misses and so is labelled non-anchored on exactly the trials that are scored as failures, whether or not anything internal has changed.

Built from each structure's own cells, the whole-track state was associated with uncued performance everywhere. Anchored trials were more often hits on uncued trials in MEC (67.9% against 35.9%, 28 sessions, p = 1 × 10⁻⁸), visual cortex (74.8% against 45.3%, 8 sessions), the subicular complex (67.6% against 41.0%, 7 sessions) and, without reaching significance, cerebellum (51.9% against 28.7%, 7 sessions; Figure S4A). The Anchoring Dependence Index was significant in MEC (+0.112, p = 0.002) and the subicular complex (+0.171, p = 0.031) and not in visual cortex (+0.067, p = 0.38) or cerebellum (+0.138, p = 0.22), on few sessions outside MEC, and matching running speed between states left MEC's index intact (+0.149, p = 0.007, 23 sessions; Figure S4C-F). A cerebellar state that tracks uncued performance is the clearest sign that something other than an entorhinal state can produce this association.

We therefore built the labels twice more, from two stretches of track that differ in what behaviour can contribute (Figure 2). Each structure's state on a trial is, as throughout, its score on the first principal component of that structure's labels; the fraction of cells anchored gives the same conclusions (Figure S2). In the task region (50–110 cm), where hits and misses diverge, labels from every structure predicted uncued outcome, cerebellum included (AUC over a circular-shift null +0.18 to +0.30), which is what a record of behaviour predicts. In the black box (−30 to 30 cm: the end of the previous lap and the start of this one, with no visual cues), hits and misses run alike — the speed difference is about a quarter of the task region's, of the opposite sign and the same on both trial types (p = 0.4) — and there only MEC (+0.059, p = 0.004) and the subicular complex (+0.080, p = 0.048) predicted uncued outcome; visual cortex (+0.000, p = 0.85) and cerebellum (+0.010, p = 0.45) did not (Figure 2G). The state on the nearest preceding cued trial, which shares none of the uncued trial's behaviour and comes entirely before it, predicted its outcome from the black box only in MEC (+0.062, p = 0.002; Figure 2H; the test is laid out on one session in Figure S5A). The cue lifts performance on cued trials (hit rate 0.79 against 0.51) but does not hold it steady: cued performance drifts over a session beyond chance as uncued performance does (Figure S5B), and cued trials that were hits go with uncued hits after them (Figure S5D), so we also regressed the cued trial's own behaviour out of its state before testing it. With it removed, the black-box state still predicted the uncued outcome in MEC (+0.042, p = 0.002) and in no other structure, and the task-region state did so in MEC (+0.039, p = 0.009), visual cortex (+0.046, p = 0.011) and the subicular complex (+0.086, p = 0.006), but not cerebellum (Figure 2H). And how far the black-box state reproduced the whole-track state tracked how persistent the session's state was in MEC (ρ = 0.63, p = 4 × 10⁻⁸, 63 sessions) and the subicular complex (ρ = 0.77, p = 0.001), but not in visual cortex (ρ = 0.25, p = 0.2), however persistent the whole-track state, and in the cerebellum the relation ran the other way (ρ = −0.56, p = 0.03; Figure S5E). In single sessions the black-box labels are noisy in every structure and recover the whole-track epochs only partly (median r 0.25 in MEC, 0.06 in visual cortex; examples in Figure 2D-F); the difference between structures is in the distribution across sessions, not in any one of them.

Together, these data indicate that the association between the anchoring state and performance is not, in MEC, a record of what the animal did. Set against the two hypotheses of Figure 2C, MEC meets all three black-box predictions of the state leading behaviour, the subicular complex one of them (its own black box), and visual cortex and cerebellum none, where a record of behaviour suffices (Figure 2I). Every structure's whole-track labels track uncued performance, but in visual cortex and cerebellum that association is carried by the stretch of track where behaviour differs; MEC, and to a lesser extent the subicular complex, carry a state that predicts performance from where behaviour does not differ, across trials, and in proportion to how stable the session's state is. We therefore treat the state as a property of MEC in what follows, and return to the other structures below.

### Grid cells and putative interneurons follow the population state most strongly

The population state is an average over cells and so does not by itself indicate which cells enter it. We considered two possibilities. If anchoring is a property of spatial coding as such, then all spatially tuned cells should follow the state. If instead it is a property of a particular subnetwork, then following should be restricted to specific cell types.

Testing this requires a definition of cell identity that cannot have been shaped by the phenomenon under study. Firing on the linear track changes with engagement and task demand, which is what we are trying to explain, so classifying cells on the same session would allow those dynamics to define the categories and then rediscover them. We therefore assigned identity entirely from the open field — grid, non-grid spatial and non-spatial classes from open-field rate maps — on a different environment and a different behaviour.

It also requires an appropriate null. Chance for this comparison is not zero: a cell that is anchored on most trials will correlate with a population that is also anchored on most trials, and we measured the resulting bias directly by circularly shifting each cell's label sequence. The null sits near +0.15 rather than at zero, and each cell was therefore compared against its own shifted distribution.

Measured this way, every identity exceeded chance, and they differed in degree (Figure 3D). Grid cells led (mean |r| = 0.347 against a chance level of 0.156, excess +0.190, p = 5 × 10⁻¹², above chance in 7 of 7 mice), followed by putative interneurons (0.289 against 0.152, excess +0.137, p = 8 × 10⁻¹⁸, 8 of 8), then non-grid spatial cells (0.236 against 0.148, excess +0.087, p = 1 × 10⁻²², 8 of 8) and non-spatial cells (0.196 against 0.141, excess +0.056, p = 2 × 10⁻¹⁷, 8 of 8). Grid cells and interneurons did not differ from one another (p = 0.71) and both exceeded the other two classes (p ≤ 3 × 10⁻⁶, Holm-corrected), while non-grid spatial cells in turn exceeded non-spatial ones (p = 1 × 10⁻⁸). The same ordering appears cell by cell: 47% of grid cells and 41% of interneurons individually beat their own null, against 32% of non-grid spatial and 20% of non-spatial cells, all well above the 5% false-positive rate (Figure 3E). Because the two leading classes are also the two most theta-rhythmic, we asked whether theta rhythmicity predicts following independently of cell type, using a theta index scored in the open field so that it cannot have been shaped by the session it is used to explain (Figure 3K). It does. The index contrasts theta-band power in a cell's instantaneous firing rate against the power in the adjacent bands, and is reliable across the two open-field sessions of a day (Spearman rho = 0.860, 15,689 cells). It separates the identities — median 0.221 in putative interneurons, 0.095 in grid cells, 0.053 in non-grid spatial and 0.022 in non-spatial cells — and it predicts agreement with the population axis beyond them: +0.209 per unit index alone (p = 1 × 10⁻²¹) and +0.177 with identity in the model (p = 1 × 10⁻¹³; mixed model with mouse and session random effects). The relationship also holds within each class taken separately: grid +0.333 (p = 0.013), non-grid spatial +0.196 (p = 4 × 10⁻¹⁰), non-spatial +0.186 (p = 0.008) and putative interneurons +0.103 (p = 0.029). Theta rhythmicity is therefore a predictor of following in its own right rather than a restatement of which classes are rhythmic. Anchoring is therefore not confined to the attractor-associated identities, but it is strongest in them, and the gap between grid cells and non-grid spatial cells — cells that are spatially tuned but carry no grid structure — is more than twofold.

That both classes exceed chance does not establish that they are coordinated with each other, since two populations could track a common signal independently. We therefore correlated every pair of simultaneously recorded cells and averaged by identity pair, again as an excess over an independent circular-shift null so that a pair which is simply anchored most of the time scores nothing for it. Grid–interneuron agreement reached +0.101 (30 sessions, p = 1 × 10⁻⁶) against +0.059 for the remaining off-diagonal pairs, and was close to either within-group value (grid–grid +0.110, interneuron–interneuron +0.126). Aligned to a transition in the population state, all four identities switched together over approximately three trials, and identity did not predict switch timing (p = 0.70).

We carried out three further analyses to establish what a non-anchored trial is. First, a non-anchored trial could reflect a firing field that has moved rather than one that has gone. Correlating each trial's map against the cell's anchored template at every circular offset, the correlation at zero offset collapsed (+0.33 to +0.07) while the best correlation over offsets fell only slightly (+0.56 to +0.53), which superficially suggests displacement. However, two unrelated cells reach +0.500 under the same best-of-offsets search, and non-anchored trials sat only 0.027 above that floor with a mean best offset of 47 cm against the 50 cm expected from a uniform choice on a 200 cm track. Non-anchored trials therefore show loss of spatial correspondence with no evidence of a coherent field elsewhere.

Second, anchoring concerns where cells fire rather than how much. Firing rate differences between states were small and their sign depended on the measure: −0.090 in log₂ when rate was averaged over position bins, −0.028 when computed as spikes per second of running, and +0.036 when trials were additionally speed-matched (all p < 0.005, n = 6,517). An effect of this size that reverses under a change of denominator and a behavioural control is not a rate effect.

Third, under the gate a cell whose two clusters both fall on the same side of its null is labelled anchored on every trial or on none, and its correlation with the population axis is then undefined. These cells are 24.5% of the population in sessions where the state actually switches, and the split is identity-dependent and runs in opposite directions: putative interneurons locked on (132 always-anchored against 7 never, consistent across mice), non-spatial cells locked off (36 against 275), while grid and non-grid spatial cells were balanced. Non-grid spatial cells dominate both locked groups only because they are approximately 70% of the population, and they lock at their base rate.

Speed coding accounts for the locking, and does so in the direction the identity split predicts. A cell tuned to running speed has a profile that repeats on every trial, because the speed profile along the track is itself stereotyped; the classifier compares each trial's rate map against the cell's own template, so such a cell is called anchored on every trial and never varies. Entorhinal speed cells are predominantly fast-spiking interneurons, which is the class that locks on (Kropff et al., 2015; Ye et al., 2018). Scoring speed modulation in the open field, so that it cannot have been shaped by the task dynamics being explained, the interneurons that lock on are markedly more speed-modulated than those that vary (median open-field speed score +0.132 against +0.072, p = 0.003; Figure 3I). Principal cells show the same direction but not reliably (+0.034 against +0.026, p = 0.16); counted across all entorhinal cells, speed-modulated cells lock on and off about equally (0.96:1) while cells without open-field speed tuning lock off, 0.57:1 (interaction odds ratio 1.70, p = 1 × 10⁻⁶; Figure 3J). Speed tuning therefore shifts locking towards the anchored side, and the locked-on cells are drawn from the speed-coding population, seen through a classifier that asks whether firing repeats across trials.

Together, these data indicate that the population anchoring state is followed by grid cells together with local inhibition, rather than by spatial tuning in general, and that these two classes form a coordinated subnetwork rather than two populations independently reflecting a shared signal.

### Grid cells are enriched medially and superficially in MEC

If grid cells and interneurons form a subnetwork, it should have an anatomical address. We localised neurons by reconstructing the position of each of the four shanks of every probe and registering recorded cells to a standardised atlas. The best-fit recording plane was fitted to device contacts rather than to cell positions, because per-cell mediolateral position is a per-shank nominal value plus jitter, and fitting to it would fit the approximation rather than the probe geometry.

Grid cells were enriched medially within session (median ρ = −0.078 against grid membership among spatial cells, negative in 17 of 25 multi-shank sessions, p = 0.028; as a share of all classified cells, ρ = −0.093, p = 0.011; Figure 4D). Because several sessions come from each animal, we also fitted a linear mixed model with mouse as a random effect (random intercept and within-session slope per mouse, sessions nested within mouse, eight mice): grid cells fell by 1.2 percentage points per 100 µm laterally within session (p = 0.04) and superficially (8.6% of superficial spatial cells against 4.0% of deep, higher in 21 of 29 sessions, p = 0.004). The other identities did not share the gradient: non-spatial cells tended to become more common laterally (ρ = +0.085, p = 0.009 across sessions, but p = 0.10 with mouse as a random effect), and neither non-grid spatial cells (p = 0.58) nor putative interneurons (p = 0.20; mixed model p = 0.94 and 0.69) varied with position (Figure 4D), so the interneurons that follow alongside grid cells are not themselves concentrated medially. Dorsoventral position predicted identity no better than chance (p = 0.99). The gradient is visible without a statistic: open-field rate maps from four sessions in one animal whose probes sat at approximately 3000, 3270, 3540 and 3720 µm, with grid and non-grid cells drawn in the ratio actually recorded, yield 12 grid cells of 27 at the medial end and 1 of 27 at the lateral end (Figure 4A).

### Cells that follow the population state are enriched medially, within the superficial grid population

Following was organised on the same axis and in the same direction, but testing this required care about which sessions can answer the question. Pooling cells across sessions produces a large gradient (ρ = −0.20, p = 8 × 10⁻⁵⁹; Figure 4E), but pooling is not safe here, because probe placement differs markedly between animals — 16.5% medial in one, 63.1% in another — so a cell's mediolateral coordinate carries information about which session it came from. The test must be made within session, where every cell shares one probe placement, and on sessions that have mediolateral variation to test: position is assigned per shank, so a single-shank session contributes only noise, and 33 of 61 sessions span under 50 µm. Restricted to the 26 sessions spanning at least 200 µm, two shank pitches or more, the gradient held (median ρ = −0.094, p = 0.004), and it held for agreement above chance as well (median ρ = −0.062, p = 0.002; Figure 4E). It also held with mouse as a random effect, so that sessions from one animal are not counted as independent: agreement above chance fell by 0.015 per 100 µm within session (p = 0.010, eight mice, 64 sessions), and the within-session slope was negative in all six animals with multi-shank sessions. Aligning cells to the border between MEC and parasubiculum rather than to probe placement showed that following above chance was highest within about 200 µm of the border and roughly halved beyond 300 µm (pooled ρ = −0.24, p = 7 × 10⁻⁴³), although within session this relation did not reach significance (median ρ = −0.035, p = 0.074, 28 sessions), and parasubicular cells next to the border followed less than the MEC cells beside them (0.169 against 0.207, p = 0.0003). Dorsoventral position (p = 0.75) and probe depth (p = 0.88) showed nothing, and for those axes the session-selection criterion made no difference, since every session varies along the shank — which indicates that the mediolateral result is specific to the axis rather than produced by the restriction. Layer behaved differently from the mediolateral axis: although it predicts identity, it did not predict following within session (median ρ = +0.028 against superficial membership, 25 of 39 sessions positive, p = 0.154; superficial +0.158 against deep +0.139 compared within session, 24 of 36 sessions, p = 0.077). Pooled across sessions the superficial bias in following does reach significance (+0.162 against +0.134, p = 0.004), but pooling is no safer here than it was mediolaterally, and the within-session tests are the ones we rely on. Three multi-shank sessions show the gradient on their own. In one, agreement with the population axis was 0.33, 0.53, 0.36 and 0.05 across the shanks from medial to lateral (204 cells, 720 µm span, ρ = −0.255, p = 0.002; Figure 4B). In a second animal, in a session whose population state changed 13 times, following was concentrated on the two medial shanks (mean agreement 0.32 and 0.44) and nearly absent from the two lateral ones (0.09 and 0.09; 404 cells, 720 µm span, ρ = −0.464, p = 1 × 10⁻¹⁹; Figure 4C). A third session, one of the most evenly balanced between the two states, shows why these profiles have to be read by region: counted over every region its most medial shank appears unresponsive (0.14), but that shank lies entirely in the parasubiculum, and across its three MEC shanks agreement falls from 0.37 to 0.12 and 0.16 (257 cells, ρ = −0.291, p = 0.0003 within MEC; Figure S7A). These three are among the strongest of the 26 multi-shank sessions, against a median within-session ρ of −0.094, and are shown because they display the gradient clearly rather than because they are typical. Not every session shows it: in a fourth animal, a session over three MEC shanks showed no gradient (0.19, 0.29 and 0.18 from medial to lateral; ρ = −0.009, p = 0.94; Figure S7B), and that animal's sessions showed the gradient weakly at best.

Two caveats apply. First, because mediolateral position predicts identity and identity predicts following, the following gradient could be an expression of the identity gradient. Restricting to non-grid cells left the effect size almost unchanged (median ρ = −0.100) but it did not reach significance at 26 sessions (p = 0.111), so we report both and claim neither over the other. Second, given the curved shape of MEC and the flat plane of a four-shank probe, mediolateral organisation could in principle be a laminar sampling artifact. It partly is. Superficial layers supply 90.3% of entorhinal recording sites in the most medial quartile and 59.8% in the most lateral, a gradient present in every animal (within-mouse median ρ = −0.447, negative in 6 of 6, p = 0.031), and the same bias carries through to the cells analysed. Stratifying the mediolateral tests by layer separates the two results. The identity gradient does not survive it: within superficial cells the effect weakens and loses significance (median ρ = −0.054, p = 0.13 at 24 sessions) against −0.078 (p = 0.028) across all layers. The following gradient does survive, and is if anything stronger within superficial cells (median ρ = −0.167, p = 0.009, 21 sessions) than across all layers (−0.094, p = 0.004). Deep layers are sampled by too few sessions to test alone. We therefore treat the mediolateral gradient in following as the more robust of the two and the gradient in identity as partly confounded with layer — which reverses the order of confidence the first caveat above would suggest.

Two further checks support the gradient. First, each cell's agreement is measured against an axis to which its own shank contributes, so a shank that dominated the axis could appear more responsive by construction; scoring every cell against a PC1 built only from the other shanks preserved the gradient (median within-session ρ = −0.081, negative in 19 of 26 sessions, p = 0.001). Second, a mixed model with shanks nested in sessions and sessions in mice, which tests position at the level of shanks rather than cells and does not count sessions from one animal as independent, found that position predicted agreement beyond identity, layer and firing rate (−0.017 per SD lateral, p = 1 × 10⁻⁴; 3,291 MEC cells on 175 shanks in 26 sessions from 6 mice, with every property measured; Figure S8E).

We then asked which property of a cell matters most. A cell's anchoring labels are built from its own spikes in the task, so a cell that fires more has less noisy labels and can show more agreement; firing rate therefore partly measures how well agreement is measured, and we held it in every model as a covariate rather than ranking it among the candidates (alone it explained 4.1% of the within-session variance; unique effect p < 10⁻⁴, Holm-corrected). Its effect is not a proxy for interneurons: it predicted following within non-grid spatial and non-spatial cells taken separately (p = 2 × 10⁻¹² and 8 × 10⁻⁸), and its interaction with identity did not reach significance (p = 0.08). Beyond it we entered eleven properties together: mediolateral and dorsoventral position, layer, identity, waveform width, and open-field spatial information, grid score, head-direction tuning, border score, speed tuning and theta modulation (Figure S8). Several of these overlap by construction — putative interneurons are classed partly on waveform, grid cells on grid score — so we ranked them by dominance analysis, which averages each factor's added variance over every combination of the others and so divides shared variance between them rather than discarding it. Together the eleven explained 6.1% of the within-session variance beyond firing rate. Mediolateral position ranked first (27% of that; unique effect p = 0.07, Holm-corrected, in a mixed model with mouse as a random effect and session and shank nested within it) and open-field spatial information second (22%; unique effect p = 0.0006), then cell type (14%), theta modulation (11%) and border score (9%) (Figure S8A). The first two are not separable: over a bootstrap of whole sessions their intervals overlapped widely (8–39% and 11–31%), and position ranked first in 58% of resamples and spatial information in 32%. Restricting the analysis to cells firing at least 1 Hz in the task (2,898 of 3,291) left the order unchanged (rank ρ = +1.00), and gradient-boosted trees, which assume no linearity, also placed position and spatial information at the top and otherwise agreed moderately (ρ = +0.66; Figure S8B). Position, theta modulation and identity overlap: lateral cells are less theta-modulated (r = −0.40) and carry less spatial information (r = −0.13), and with every factor in the model the position coefficient fell from −0.017 to −0.012 per SD but remained significant (p = 0.006), while theta modulation's unique contribution did not (p = 0.09; Figure S8C, E); the gradient in following and the theta-modulation effect of Figure 3K are partly one observation. Dorsoventral position, layer and head-direction and speed tuning explained little or nothing. Most strikingly, in the mixed model all twelve properties together, firing rate included, explained 7.3% of the variance in agreement above chance, against 10.2% for the animal, 8.7% for the session within it and 5.0% for the shank (Figure S8D): how strongly a cell follows the population axis depends far more on which population it sits in than on what kind of cell it is.

Together, these data indicate that the cells that follow the population state occupy a specific region of MEC. The mediolateral gradient belongs to following itself. The superficial bias belongs to identity: layer separates grid cells from other spatial cells but does not separate followers from non-followers within session, so the responsive subnetwork is medial, and lies within the superficially biased population that grid cells occupy, rather than being independently superficial. At this sample size we cannot separate an anatomical gradient in following from the anatomical gradient in identity.

### Monosynaptic connectivity does not account for shared anchoring

That grid cells and interneurons agree is a trial-level statistic and remains compatible with two populations independently tracking a common signal. Putative monosynaptic connections allow the same question to be asked in millisecond spike timing. We reasoned that if the anchoring state is propagated through the local circuit, then pairs of neurons that are synaptically connected should share the state more strongly than pairs that are not.

Connections were identified from cross-correlograms (Figure 5). Interneuron-to-grid was the strongest pathway in the dataset (3.20% of testable ordered pairs, 4.8-fold over within-session identity shuffling, p = 0.0005). Excitatory connections were an order of magnitude sparser and not organised by identity in the same way: grid-to-grid was among the densest (0.28%) but no more frequent than identity shuffling predicts (1.2-fold, p = 0.23). Detecting the inhibitory half required extending the standard criteria, which test for a causal peak and therefore detect excitation only, onto the lower tail of the same Poisson test. Two features of the resulting connections indicate they are not an artifact of that extension: they are slower than excitatory connections (median 3 against 1 ms), and they originate from waveform-classified interneurons at 4.9 times their population share, neither of which the detector can produce by construction. The rate cut that completes the interneuron call is a convention rather than a boundary: across all narrow-spiking cells, the share that inhibit rises smoothly with firing rate with no upward step at the cut, and below it narrow cells still inhibit four times as often as broad-spiking cells of the same rate while making excitatory connections as often as they do, so they form a graded mixture whose fast end the call selects (Figure S19). The pairing seen in the trial-level statistics is therefore present in the wiring.

It nonetheless does not carry the state. Compared against unconnected pairs from the same session, of the same identity pair and at a similar probe distance (±40 µm), connected pairs shared the anchoring state no more strongly: grid–interneuron +0.163 against +0.152 (n = 280, p = 0.60) and interneuron–interneuron +0.090 against +0.092 (n = 165, p = 0.99). Both comparisons resolve effects of 0.034 at 80% power, approximately a third of the size of the identity effect they are testing against, so these are informative nulls rather than absence of evidence. Grid–grid pairs, fewer and so less tightly measured (n = 57, minimum detectable effect 0.105), did not differ either (+0.419 against +0.358, p = 0.10). Connected pairs of the remaining identities showed a small excess (+0.075 against +0.067, n = 5,293, p = 6 × 10⁻⁵), a tenth of the identity effect. Pairs that include a narrow-spiking cell show no excess at any firing rate (Figure S19I).

Together, these data indicate that anchoring travels with what a cell is rather than with what it is wired to. This is the result on which the rest of the paper turns: a state that is shared by cells of a given identity, but not more strongly by the subset of those cells that are synaptically connected, is unlikely to be propagated cell to cell within the circuit that expresses it, and is more consistent with a common input to which grid cells and local inhibition are more sensitive than other cells are.

### Transitions in the population state coincide with changes in pupil-linked engagement

If the state is imposed from outside the local circuit, the question becomes what the population is listening to, and a global behavioural variable is the natural candidate. Pupil diameter is the standard non-invasive index of the arousal and engagement axis (Reimer et al., 2016) and was available on 80 of 81 virtual-reality sessions.

Pupil radius was smaller in the anchored state (−0.593 z paired within session, p = 1 × 10⁻⁸, 29 sessions; Figure 6H) and changed at transitions: entering the anchored state it fell by 0.414 z, and entering the non-anchored state it rose by 0.493 z (p = 1.7 × 10⁻⁷ and 4.4 × 10⁻⁸; Figure 6). Pupil radius did not change instantaneously, with the single trial spanning a transition accounting for only 16–31% of the total change. Because the classifier's median filter smooths each cell's label sequence over ±2 trials, these data cannot distinguish a genuinely graded change from an abrupt one whose onset is imprecisely timed, and we make no claim about which it is.

A constricted pupil is read as low arousal when it accompanies disengagement, and we therefore asked directly how pupil size relates to performance. Binning trials by within-session pupil z into deciles, the hit rate fell at every step from 0.826 in the smallest decile to 0.391 in the largest (14,011 trials, 58 sessions), and the anchored fraction fell with it. A mixed model gave −0.123 per z (p = 8 × 10⁻²⁷¹). Adding a quadratic term did not produce an inverted U: the quadratic coefficient was positive (+0.018, p = 3 × 10⁻¹⁵), placing the minimum of the fitted curve at z = +3.4, beyond the observed data, so that within the range the animal occupies the relationship is monotonically decreasing. The relationship was not a consequence of running: mean speed was flat across pupil deciles (37–40 cm/s) and controlling for within-session speed left the coefficient unchanged (−0.128, quadratic +0.011).

The shift is tonic rather than localised, and this is what identifies it as a change in engagement rather than attention paid at particular points on the track. Comparing pupil radius between states in each of 50 position bins, the difference has the same sign in every bin, reaches significance in 49 of them, and varies little along the track (mean −0.236 z, range −0.367 to −0.114, SD across bins 0.061 z). It does not trend with position (Spearman ρ = −0.079, p = 0.58), and the reward zone is if anything slightly less affected than the rest of the track (−0.204 against −0.240). A state in which the animal attended selectively to task-relevant locations would concentrate the difference at those locations; instead the whole traversal is shifted.

Together, these data indicate that the anchoring state tracks a global behavioural variable indexed by pupil diameter, and that the anchored, constricted-pupil state is the one in which the animal performs. Because performance improves monotonically as the pupil narrows, we interpret this state as one of focused task engagement — a selective, exploitative mode (Aston-Jones and Cohen, 2005) — rather than as low arousal in the sense of drowsiness, which the behaviour excludes.

### Visual cortex shares a weaker version of the entorhinal state

Beyond predicting performance, the structures differ in whether they carry a state at all once sampling is equated. Building an axis from one half of a structure's cells and scoring it on the other half, so that a direction fitted to noise cannot score, and holding the number of cells at 8 per half so that MEC's hundreds carry no advantage, a held-out state was detectable in 26 of 60 entorhinal sessions, 7 of 9 subicular sessions and 4 of 20 visual sessions (Figure S9). Where a state was present it was one-dimensional in almost every session of every structure (25 of 26, 7 of 7 and 4 of 4): the first component's excess over its null was +0.033, against +0.0002 for the second, so the label matrix is effectively rather than strictly one-dimensional (the second component clears its null, p = 0.005). A second component is also what MEC would show if it held more than one stable map, each expressed by a subset of cells and switching on its own schedule (Low et al., 2021), and such a component would grow as more cells are sampled. Simulating that case with the same analysis, label noise set so that one simulated state matches MEC's first component, two independent populations of equal size put the second component +0.017 above its null at 32 cells per half, and a 75/25 split +0.005; MEC's second component stayed at its null at every sample size (−0.0008 at 32 cells per half, 45 sessions, p = 0.30; +0.0019 at 64, 20 sessions, p = 0.60; Figure S9A, B and E).

Where visual cortex and MEC were recorded on one shank, the two states were related, asymmetrically (Figure 7). In the 10 sessions whose cells reach at least 500 µm into both structures, the visual state stepped at entorhinal switches, 56% as far as MEC over the first five trials and beyond a time-shift null (p = 0.005), whereas at visual switches the entorhinal step (44% as far as visual cortex) did not clear the null (p = 0.055). Where both axes were reliable the two correlated at a median 0.99 of the ceiling their own noise allows (6 sessions). Cell by cell, visual cells followed the entorhinal axis as well as their own (median agreement above chance 0.027 against 0.026, p = 0.72); entorhinal cells agreed more with their own axis than with the visual one, but not reliably (0.063 against 0.049, p = 0.17), and agreement with the entorhinal axis did not fall off with distance from the border on either side. Visual cortex therefore carries a share of the entorhinal state rather than an independent state of comparable strength.

Together, these data indicate that MEC carries the anchoring state most strongly among the structures we recorded. Where another structure carries a state at all, it is the same one-dimensional state, and in visual cortex it follows the entorhinal one more than the reverse.

A shared state does not require that every structure leaves the task reference frame at the same moments, and the cells that never leave it are not distributed as a shared state would suggest. Figure 3J showed that the entorhinal excess of cells locked permanently into the anchored mode is carried entirely by cells that are speed-modulated in the open field; among entorhinal cells with no open-field speed tuning the lock is if anything the other way, 193 permanently anchored against 248 permanently non-anchored. Repeating that count in every recorded structure turns up one exception. In visual cortex, cells with no open-field speed tuning lock into the anchored mode 102 against 19, a fivefold excess where entorhinal cortex shows none (odds ratio 6.9 against the entorhinal cells, p = 3 × 10⁻¹⁶). It does not depend on the speed restriction either: among visual cells that are speed-modulated in the open field the ratio is 8.8:1, against 0.8:1 and 1.4:1 for the two entorhinal halves. These are cells that hold their field across the trials on which the entorhinal population reorganises, and they are not explained by the speed signal that accounts for the entorhinal lock. They make visual cortex's locked block larger than MEC's in both example sessions of Figure 7 (44% against 12% and 55% against 33%); in those cells the field is the same on every trial, whereas a following cell has a field in one state and little or nothing in the other.

What those visual cells are doing is not a second anchoring signal. Where these cells fire is not peculiar to visual cortex: clustering each population on the shape of its position profile, peak positions are far from uniform in both structures (KS p = 3 × 10⁻¹⁸ and 2 × 10⁻¹⁰) and concentrate in the same places, the first 50 cm and the last 25 cm of the track. What separates them is what the firing follows. Two variables are confounded with position by the task itself: running speed, because the animals slow into the reward zone and run fastest after it, and screen luminance, which was not recorded but is indexed inversely by pupil radius against position — pooled over 23 sessions the pupil is most constricted at 106 cm, inside the reward zone, and most dilated near 22 cm, a swing of 2.2 z.

Testing either against zero would not be informative, because both are smooth functions of position and any smooth function of position resembles a smooth firing profile. We therefore compared each population's median correlation with each regressor against 500 phase-randomised surrogates of that regressor, which preserve its power spectrum and so its smoothness while destroying its relationship to position, and we split each structure by open-field speed tuning at this point rather than when selecting the cells. Entorhinal cells follow the track's speed profile and not its light, whether or not they are speed-modulated in the open field (+0.14, p = 0.046 without speed tuning; +0.22, p = 0.022 with it; luminance p = 0.96 and 0.41). Visual cells are the opposite, and only in one half of the population: those without open-field speed tuning follow the light and not the speed (luminance median r = +0.29, p = 0.042; speed p = 0.82), while the speed-modulated visual cells follow neither. The visual cells also carry the beacon: reward-zone firing differs between cued and uncued trials across the 102 untuned cells (p = 0.009) and across all 277 (p = 0.008). The luminance result is marginal, and we treat it as suggestive.

We are explicit about what this test can and cannot say. It establishes that each relationship is present, but not how large it is: cross-validated variance explained does not clear the same null for any regressor in any population (best p = 0.075), so we do not quantify the share of the profile either confound accounts for. What can be said positionally is where the structure of these cells lies. Nearly half of the variance of their position profiles falls inside the 30 cm black box at each end of the track — 50% for the visual cells and 45% for the entorhinal ones, against the 30% of the track those boxes occupy — while the reward zone is the one place it is scarce. The persistently anchored cells of both structures are organised around the ends of the track, where each traversal begins and ends, rather than around the goal.

We therefore read these visual cells as following features of the scene — its luminance structure and the beacon — which repeat on every lap, rather than as carrying an anchoring signal of their own. The consequence is the point of interest. The task reference frame remains legible in this subset of visual cells throughout, including on the trials during which the rest of both structures has left it, so the information MEC would need in order to stay anchored is available and is not being used. Whatever governs the entorhinal state is therefore not a failure of sensory access.

### The population state is associated with frequency-specific changes in the local field potential

If anchoring is a network state rather than a property of individual cells, it should be visible in the local field potential. We considered two possibilities. A uniform change in the amplitude of the field — arising from a change in the spiking contribution to the LFP, or from electrode referencing — predicts that power moves in the same direction at all frequencies. A change in the balance of inputs or in local processing predicts that it does not.

To distinguish these we computed Welch spectra per trial from the entorhinal LFP across the full range from 1.9 to 150 Hz rather than integrating over bands fixed in advance, because a band split whose "gamma" runs from 30 to 80 Hz cannot detect a change that reverses sign inside it. Spectra were whitened by multiplying power by frequency so that peaks are visible against the 1/f background, and z-scored within session so that no recording's absolute amplitude dominates. Across the 25 sessions with at least 8 trials in each state, the difference between states changed sign across the gamma range (Figure 8E and F): mid gamma (60–100 Hz) fell by 0.094 (p = 0.011, lower in 19 of 25 sessions) and high gamma (100–150 Hz) by 0.122 (p = 0.003), while slow gamma (30–48 Hz) rose by 0.101 (p = 0.0008, 20 of 25). Theta fell, but not reliably (−0.069, p = 0.22, lower in 18 of 25); it had reached significance before units failing the ISI criterion were excluded (−0.085, p = 0.032), and we do not treat it as a result. Delta (+0.100, p = 0.059) and beta (+0.071, p = 0.11) did not change. The reversal is orderly rather than a scatter of band results: the pooled difference profile is positive to approximately 60 Hz and negative above it, and crosses zero within the gamma range in 24 of the 25 sessions at a median of 62 Hz, so the two gamma effects are two sides of one spectral rotation rather than two independent findings. Because the difference reverses sign, no uniform change in amplitude, referencing or spiking contribution can account for it.

Because the proposed account of these band changes places fast-spiking interneurons at the centre of the gamma rhythm, we measured spike coupling to gamma directly, with pairwise phase consistency and with the field taken at least 120 µm from each cell so that a cell's own waveform could not stand in for the field (Figure S12). Coupling is present and local, falling from the cell's own channel to 120 µm away and to near zero at 1.2 mm, but it does not distinguish interneurons: they are no more coupled than principal cells in either band (p = 0.96 and p = 0.63 over sessions) and grid cells are the most coupled class in both. What does hold is the phase relationship — in 60–100 Hz gamma interneurons follow the principal cells by a median 43° (p = 5 × 10⁻⁶, later in 26 of 31 sessions), the direction pyramidal–interneuron gamma predicts, with no such lag at 30–48 Hz. None of this coupling changes with the anchoring state (four comparisons, Holm-corrected p ≥ 0.10).

We checked that the slow-gamma increase is not mains contamination. The band is taken as 30–48 Hz, below the 50 Hz line, and the line-frequency bins are excluded throughout; the 48–52 Hz bins on their own change in the same direction (+0.115, p = 0.027), as expected if the slow-gamma rise extends through them, so we cannot use them as a mains-only control.

Theta's nesting of gamma changed for one band only. Quantified as Tort's modulation index (Tort et al., 2010) over 18 phase bins with a phase-shuffle null subtracted, theta–fast-gamma coupling fell in the anchored state by 16.9% (p = 4 × 10⁻⁵, lower in 20 of 25 sessions), while theta–slow-gamma coupling, taken over the same 30–48 Hz band as its power, did not change (+2.8%, p = 0.92, lower in 11 of 25) (Figure 8G). The band whose power falls is therefore also the band that uncouples from theta, while the band whose power rises remains nested as before. We note that the slow-gamma null is the weaker of the two, since its absolute modulation index is approximately seven times smaller, and we therefore report this as an unsupported difference rather than as a demonstrated invariance.

Tested pairwise within session, the two changes are equal and opposite. The difference index (slow minus fast) was positive in 20 of 25 sessions (+0.195, p = 2 × 10⁻⁴), while their sum was not distinguishable from zero (+0.007, p = 0.79), and neither was the change across the whole 2–200 Hz range (−0.033, p = 0.30) (Figure 8H). The same contrast in log power rather than in per-frequency z gives a sum of +0.002 (p = 0.75), so the balance is not an artifact of z-scoring each frequency. Power therefore moves from fast to slow with no detectable net change. Two qualifications. The sum is zero on average and not session by session: the scatter about the equal-and-opposite line is wide, and a session that gains slow gamma is not reliably one that loses fast gamma by the same amount. And the balance is per hertz — the fast band is 40 Hz wide against slow's 18, and weighting each band by its width moves the sum to −0.29 (p = 0.11). What the data support is that power moves from fast to slow, not that the total is conserved.

Measured directly, as the RMS of the 6–10 Hz signal on speed-matched trials rather than as a band of the per-frequency z-scored spectrum, theta amplitude was lower in the anchored state (Δz = −0.268, p = 0.015 across the 33 sessions with speed-matched trials in both states; an amplitude fall of 2.0%, p = 0.040). This is not a shift of the rhythm out of the analysis window: instantaneous frequency was unchanged (−0.010 Hz, p = 0.43) and the spectral peak moved by −0.108 Hz (p = 0.06), far too small to move power out of a 4 Hz band. The effect is small, and the spectral measure, which normalises each frequency within session, does not resolve it.

The relationship between theta and behaviour changed more robustly than its amplitude. Theta amplitude and frequency both track running speed, and that coupling fell by about 40% during anchored epochs: on the 25 sessions with at least 15 trials in each state, the within-session regression slope of theta amplitude on speed fell from 0.343 to 0.198 (speed × state interaction, p = 0.018) and of theta frequency on speed from 0.0126 to 0.0082 Hz per cm/s (p = 0.016), with the corresponding correlations falling from 0.439 to 0.262 (p = 0.001, lower in 17 of 25 sessions) and 0.423 to 0.219 (p = 1.4 × 10⁻⁴, 20 of 25). Mice do run more uniformly when anchored (speed SD 6.08 against 8.31 cm/s, p = 2 × 10⁻⁵), which attenuates a correlation on its own, but several observations indicate that this is not the explanation. The regression slope is insensitive to range restriction and fell by the same factor; the per-session change in correlation did not track the per-session change in speed variability (ρ = −0.01, p = 0.92); restricting both states to their common speed range left the slope difference intact (0.12 against 0.34, p = 0.008); and a circular-shift null on the state vector, which preserves run structure and within-session drift, gave p = 0.005. That the gain changes rather than only the level distinguishes this from a state in which the animal simply runs differently.

Because theta's coupling to speed changes while the rhythm itself does not, we asked directly whether the cells that carry the speed signal into entorhinal cortex change their speed coding with state. Entorhinal speed cells are reported to be largely fast-spiking inhibitory neurons that inherit a speed signal from the medial septum (Kropff et al., 2015; Justus et al., 2017; Ye et al., 2018), so the prediction is specific: if the anchored state reflects a reduction in that septal speed pathway, the affected cells should be fast-spiking speed cells. We identified them entirely outside the virtual-reality session, from waveform class and the open-field speed score, and divided all entorhinal cells into four groups on those two criteria alone.

The classification reproduced the reported anatomy. Speed modulation was enriched approximately twofold among putative interneurons (58.7% against 41.5% of principal cells, odds ratio 2.01, p = 1.1 × 10⁻¹³), the median open-field speed correlation was three times higher in interneurons than in principal cells (p = 5 × 10⁻²³), and the relationship was continuous rather than categorical, with narrower waveforms and higher firing rates both predicting stronger speed modulation (ρ = −0.137 and +0.118, p < 10⁻¹⁸). The open-field labels also transferred to the task: on the virtual track, cells classified as speed interneurons in the arena had a median speed slope of 0.138 Hz per cm/s against 0.012 for non-speed interneurons, 0.010 for speed principal cells and 0.0008 for non-speed principal cells, a twelvefold separation obtained from a label assigned in a different environment.

In those cells speed coding did not change with the anchoring state; in principal cells it weakened. We fitted each cell's firing in both states in one Poisson model, with a position map and an intercept for each state, running speed, and speed's interaction with state, on the two states' common speed support. The speed coefficient is then a gain, the proportional change in rate per 10 cm/s, which a change in overall firing cannot mimic, and with position in the model it is estimated from departures from the expected speed profile alone. Open-field speed interneurons kept their gain: 7.7% per 10 cm/s when not anchored and 7.4% when anchored, a change of −3.9% (95% CI −16 to +9%, hierarchical bootstrap over mice and sessions; p = 0.48, mixed model with mouse as a random effect; 203 cells, 24 sessions, 6 mice), and +3.0% (−15 to +14%) with position left out of the model. That interval excludes a change as large as the 42% fall in theta's speed slope. Speed principal cells did change: their gain fell by 30% when anchored (95% CI −66 to −10%, p = 0.008; lower in 22 of 27 sessions), and neither a finer position map (−29%) nor a 1 Hz floor on firing rate (−27%) removed it. The change appears only with position held (−5%, p = 0.52 with position left out). On the track speed and position are collinear, more so when anchored, so without position the speed coefficient also carries the cells' spatial firing. Cells without open-field speed tuning, on near-zero gains, showed nothing we interpret. Population decoding of unexpected speed, with position removed from both speed and rates, did not differ reliably between states (r = 0.65 against 0.72, p = 0.25), although there is less unexpected speed to decode when anchored (SD 13.5 against 17.6 cm/s, p = 6 × 10⁻⁸; Figure S13).

Speed modulation also did not predict how strongly a cell followed the population state. Pooled across entorhinal cells the two were weakly correlated (ρ = +0.066, p = 3 × 10⁻⁶), but entering both predictors in one model leaves cell class carrying the effect and speed modulation carrying none (putative interneuron +0.069, p = 1.2 × 10⁻⁶; speed modulation +0.005, p = 0.21). The pooled correlation is a composition effect: interneurons are both the most speed-modulated cells and the strongest followers, so pooling manufactures an association between two properties that are independent within class.

Finally, we asked whether discrete gamma events rather than continuous power carry the state or the task demand, reasoning that if gamma cycles correspond to discrete processing episodes then uncued trials, which require path integration, should contain more of them. Counting supra-threshold envelope excursions lasting at least one gamma cycle, expressed per theta cycle across 10,802 trials from 44 sessions, the raw comparison appeared to support this: fast-gamma events were more frequent on uncued trials (+0.0057 per theta cycle, p = 0.016). The effect did not survive control. Adding trial speed and theta frequency to the model reversed its sign (−0.0054, p = 4 × 10⁻⁵), and adding band power removed it entirely (+0.0003, p = 0.68). Event counts here track power and running rather than task demand, and we report this prediction as tested and not supported. The same analysis did reveal an organisation by track position: slow-gamma event rate peaked at 92 cm, within the reward zone, in 40 of 44 sessions between 70 and 130 cm, surviving control for speed and band power (+0.356 Hz for 80–110 cm against the rest of the track, p = 5 × 10⁻⁸), while fast-gamma events showed no such peak. This did not interact with cue condition (p = 0.93) or with anchoring state (p = 0.77), and so stands beside the state result rather than explaining it.

Together, these data indicate that the population anchoring state is accompanied by a spectrally structured change in the entorhinal field potential, in which mid and high gamma fall while slow gamma rises and theta amplitude falls slightly, and by a reduction of roughly 40% in the coupling of theta amplitude and frequency to running speed.

### The grid attractor keeps running when anchoring is lost

The account we propose in the Discussion supposes that the non-anchored state is a grid attractor that is still running but no longer corrected to the task frame, rather than one that has come apart. To test this we gave each grid cell phase offsets on its module's torus by the spectral method of Gardner et al. (2022), projected the population onto them, and compared the resulting bump with a shuffle of which offset belongs to which cell, which leaves every firing rate intact. On anchored trials the module's phase was regular and tied to position; on non-anchored trials it lost that order (Figure 9C). The bump itself persisted. Across 22 sessions it exceeded its shuffle by +0.056 when anchored and +0.040 when not (both p = 5 × 10⁻⁷), modestly weaker without anchoring (p = 0.005) and unchanged by equating running speeds (Figure 9D, E). It did not fall at the 130 switches into the non-anchored state, nor decay within it (not shown). It also kept pace with the animal: averaged over 2.5 s, which removes most of a distortion that the readout itself introduces at shorter scales, the bump's speed correlated with running speed in both states (median r = 0.186 anchored and 0.128 non-anchored, both above shuffle), less closely once anchoring was lost (p = 0.001 with mouse as a random effect; Figure 9F). Its gain, the bump's advance per cm run, was 0.93 when anchored, near 1 as calibrated, and 0.60 when not (p = 0.003 with mouse as a random effect; Figure 9G), a shortfall that accumulates to most of a lattice cycle over a trial, so that the phase at a given place is effectively re-drawn from one trial to the next.

To see what the proposed mechanism predicts of these measures, we simulated a module of a gated continuous attractor, in which an attentional gate on landmark correction is the only thing that changes, together with a simulated mouse that slows and stops where its own bump says the reward zone is (Figure 9A). We made the simulation as noisy as the recordings, giving each simulated cell the firing rate and over-Poisson variability of a recorded grid cell and adding noise to path integration, and put it through the same pipeline (Figure 9B). The anchoring classifier recovered the gate as the population state (PC1 positive on 94% of gate-open trials and none of the gate-shut ones), and behaviour followed it: with the gate open the simulated mouse stopped in the reward zone on every trial, with it shut on 6%, because the bump it read its position from had slipped. The simulated bump persisted in both states, and with the gate shut its phase scattered from trial to trial as the recorded one does. Two features of the recordings were not reproduced: the simulated bump remained about five times stronger than the recorded one and barely weakened when anchoring was lost (+0.282 and +0.252 above shuffle), and its speed tracked the animal's less closely when anchored, not more, because the open gate pulls the bump back into register at the start of every trial. The recordings are therefore consistent with an attractor that keeps running but goes uncorrected, with a modest loss of coherence that the gate alone does not explain.

## Discussion

Our results indicate that anchoring of entorhinal spatial firing to a task reference frame is a population state of MEC that tracks engagement and is not carried by the detectable local wiring. We find that anchoring is a coordinated property of the recorded population rather than of single neurons (Figure 1), that it is expressed most strongly by grid cells together with putative interneurons, at roughly twice the level of spatial cells without grid structure (Figure 3), and that these cells occupy a medial position within MEC, inside the superficially biased population that grid cells occupy (Figure 4). Although grid cells and interneurons are synaptically coupled, with interneuron-to-grid the strongest pathway we detect, synaptically connected pairs do not share the anchoring state more strongly than matched unconnected pairs (Figure 5), so the coordination is not explained by the connections we can detect. Transitions coincide with changes in pupil-indexed engagement (Figure 6). Among the structures recorded on the same shanks, MEC stands out: other structures' labels track performance largely by recording the animal's behaviour, while the entorhinal state predicts performance from a stretch of track where behaviour does not differ (Figures 2, S4 and S5); visual cortex carries a share of the entorhinal state, following its switches more than MEC follows visual ones, while a subset of visual cells holds the task reference frame through the trials on which the rest of both structures leaves it (Figure 7). The state is accompanied by frequency-specific changes in the local field potential (Figure 8).

### Shared anchoring tracks cell identity rather than synaptic partnership

Coordinated switching among grid cells is usually interpreted through continuous attractor dynamics, in which recurrent connectivity enforces a shared network state. Our monosynaptic analysis does not support that interpretation for anchoring specifically. Two grid cells agreed at approximately the same level whether or not a synapse was detectable between them, and the grid–interneuron comparison would have resolved an effect a third the size of the identity effect it was testing against. We emphasise what this does and does not show. It does not show that the entorhinal circuit lacks attractor dynamics, nor that recurrent connectivity is irrelevant to grid firing; our sampling recovers only a small fraction of the connections present, and detectable monosynaptic connections are a biased and sparse sample of the circuit. What it shows is that, within the pairs we can test, synaptic partnership adds nothing to identity in predicting shared anchoring. The most economical account of that result is a common input to which grid cells and local inhibition are more sensitive than other entorhinal cells are.

The identity dependence is itself informative about the candidate input. Putative interneurons followed the state as strongly as grid cells and locked almost unanimously into the anchored mode, while non-spatial cells locked out of it. Neuromodulatory and septal projections to MEC target inhibitory populations preferentially (Gonzalez-Sulser et al., 2014; Desikan et al., 2018), and a common input arriving through local inhibition would be expected to produce exactly this pattern: strong expression in interneurons and in the principal cells they most densely innervate, weak expression elsewhere.

The same dissociation appears a second time, with a different candidate property. Because entorhinal speed cells are predominantly fast-spiking interneurons, and interneurons are the strongest followers of the state, speed modulation is an obvious candidate for what the followers have in common. It is not: pooled across cells the two are weakly associated, but within class the association disappears entirely, and in a model containing both, cell class carries the effect while speed modulation carries none. What predicts a shared anchoring state is what a cell is, not whether it is synaptically connected to another follower and not how strongly it is tuned to running speed. Two functional properties have now been tested in place of identity and neither substitutes for it.

### MEC stands out, and a record of behaviour can pass for a state

Asking whether the anchoring state is entorhinal required two controls that a first comparison lacks. Each structure had to describe the state with its own cells, so that MEC was not the frame of reference; and the labels had to be tested where behaviour could not produce them, because a classifier that compares rate maps across trials will label as non-anchored any trial on which a cell's firing follows a different behaviour, and on misses the animal runs differently through the reward zone. Without the second control the result looked global: whole-track labels from visual cortex, the subicular complex and even cerebellum all tracked uncued performance. With it, the picture separates. Labels from the task region predicted outcome in every structure, as a record of behaviour should; labels from the black box, where hits and misses run alike, predicted outcome only in MEC and, more weakly, the subicular complex, and the preceding cued trial predicted an uncued trial's outcome from the black box only in MEC, even with that trial's own behaviour removed.

The cerebellum is the instructive case. It was included as a structure with no parahippocampal connectivity that could explain a shared anchoring state, and its whole-track state tracked uncued performance, which taken alone would have argued that the state is global. Its cells' open-field position coding is a single shared map rather than cell-specific fields, its black-box labels do not predict outcome, and its black-box state does not reproduce its whole-track state however persistent that is. A cerebellar state that tracks performance is therefore what a record of behaviour looks like, and it is a caution against reading any whole-track association between a population's labels and performance as evidence of an internal state.

Visual cortex sits between the two. Its state is related to the entorhinal one, stepping at entorhinal switches and correlating with the entorhinal axis close to the ceiling its own noise allows where both are reliable, but the relationship is asymmetric: visual cortex follows entorhinal switches more than MEC follows visual ones, visual cells follow the entorhinal axis as well as their own while entorhinal cells prefer theirs, and at matched cell count a held-out state is detectable in a fifth of visual sessions against nearly half of entorhinal ones. We do not claim that the state originates in MEC; the asymmetry is a statement about where it is expressed most strongly, and these recordings cannot establish its source. What they do establish is that the entorhinal state is not a byproduct of behaviour in the way the cerebellar and much of the visual association are.

### What the field potential adds, and what it does not settle

The spectral result constrains mechanism more than the amplitude result does. A change confined to overall amplitude would be compatible with many uninteresting explanations, including a change in how much spiking contributes to the field or in electrode referencing. That the difference reverses sign within the gamma range excludes those, because each acts in one direction at all frequencies. The accompanying loss of theta–fast-gamma coupling, with theta–slow-gamma coupling preserved, points in the same direction: the band that falls in power is the band that also uncouples.

We resist a stronger reading. Slow and fast gamma in the entorhinal–hippocampal system have been associated with different input streams (Colgin et al., 2009) and, in one influential framework, with internally guided retrieval and externally driven encoding respectively (Bieri et al., 2014). An animal localising a reward zone by path integration is in the internally guided case, and that is also the condition in which anchoring matters most for behaviour, so the direction of our effects is the one that framework would predict for a shift toward internally guided processing in the engaged state. But those band assignments derive largely from hippocampal work, our recordings are entorhinal, and we have not shown that the two bands here carry the inputs the framework assigns them. We also note that although the two gamma changes are equal and opposite on average, the per-hertz balance does not survive weighting by bandwidth, so we describe power as moving from fast to slow rather than as conserved between the bands.

The decoupling of theta from running speed is robust to every control we applied but remains mechanistically unexplained. The most natural reading, that the velocity signal driving the entorhinal network is down-weighted when position is pinned by landmarks, predicts changes in the cellular speed code that we observe only in part: the fast-spiking speed cells that carry the septal speed signal, defined entirely from the open field, keep their speed gain, with an interval that excludes a change the size of the field-potential effect, while speed-modulated principal cells lose about a third of theirs once position is held. We tested the gamma-as-discrete-processing-episode hypothesis directly and it was not supported: apparent differences in event counts between cued and uncued trials tracked running speed and band power rather than task demand.

### Limitations

Three limitations bear on the central claims. First, the monosynaptic null is a null, and although both informative comparisons resolve effects a third the size of the identity effect, absence of a wiring contribution within detectable pairs does not exclude one within the much larger set of connections we cannot detect. Second, the non-entorhinal recordings sit on the same probe as the entorhinal ones, so for the field-potential analyses volume conduction cannot be excluded, and a shared effect was always going to be ambiguous where a divergent one would have been decisive. Third, the classifier's median filter smooths each cell's label sequence over ±2 trials, so our data cannot distinguish a graded transition from an abrupt one that is imprecisely timed, and the temporal structure of state transitions should be regarded as unresolved.

### Ideas and speculation

If the anchoring state follows engagement and is not carried by the local wiring, then the relevant question for grid cell function shifts from what the entorhinal circuit computes to what it is listening to, and when. One implication is that the availability of a usable grid code may be set by processes that have nothing to do with space. A mouse that is disengaged has a grid network that is not anchored to the task, and on those trials it localises the reward less often, even though nothing about its spatial circuitry need have changed. If this generalises, variation in path integration ability between individuals may reflect variation in engagement rather than in path integration machinery as such, which would be relevant to the interpretation of spatial deficits in ageing and in neurodegenerative disease.

A second implication concerns experimental design. Cue-rich virtual environments, which are widely used to study grid cells, engage behaviours that our results suggest can be solved without anchored grid firing. In such environments the anchoring state may vary without behavioural consequence, and grid activity recorded there may be only loosely coupled to what the animal is doing.

Finally, the identity of the common input remains open, and two septal candidates that seemed natural are now both constrained by the data. Medial septal GABAergic neurons are the obvious one, since their inhibition disrupts grid periodicity and phase precession together (Robinson et al., 2024), but the direction of our field-potential result does not fit an account in which the non-anchored state is reduced septal drive: theta amplitude is lower in the anchored state, which is the state in which the code is best locked to the track. Spike–theta phase locking is also unchanged between states, which is what an intact pacemaker looks like.

That suggested a cell-type distinction, since the septal pacemaker and the speed signal reaching entorhinal cortex are carried by different projections (Fuhrmann et al., 2015; Justus et al., 2017), and a reduced speed–theta gain with preserved spike–theta timing resembles a change in the speed pathway with the pacemaker intact. The speed-pathway account is now also difficult to sustain. Entorhinal speed cells are predominantly fast-spiking inhibitory neurons, and we confirm that here; but those cells' speed gain does not change between anchoring states (−4%, 95% CI −16 to +9%), which excludes a change the size of the 42% fall in theta's speed slope. The speed signal arriving on the cells that carry it looks preserved while its expression in the field potential is not. Further along it is not preserved: speed-modulated principal cells respond about 30% less to unexpected speed when anchored, close to the fall in theta's speed slope. That would place the decoupling between the interneurons that receive the speed drive and the principal cells, rather than in the drive itself — a reading these data are consistent with but do not test.

A third septal projection is constrained by neither result. The medial septum and diagonal band send cholinergic as well as GABAergic and glutamatergic axons to entorhinal cortex, more densely to its medial than its lateral division (Desikan et al., 2018), terminating in the superficial layers where the grid network and its feedback inhibition lie. Neither observation that narrows the other two candidates bears on this one: a change in cholinergic tone requires no change in the septal pacemaker, whose signature — preserved spike–theta phase locking — we observe, and no change in the speed signal arriving on the cells that carry it, which we also observe. It predicts the direction of the field-potential result rather than being embarrassed by it. Cholinergic tone drives theta, suppresses delta and favours fast over slow gamma, so a lower tone in the anchored state predicts lower theta, higher delta, lower fast gamma and higher slow gamma; we find lower theta amplitude, lower fast gamma and higher slow gamma, while delta did not change reliably; and because acetylcholine modulates gamma power rather than gamma frequency, it further predicts that the gamma peak should not move between states, which it does not.

Our pupil measurement is better suited to this reading than it would ordinarily be. Rapid pupil dilations track noradrenergic activity, whereas sustained dilations during locomotion are accompanied by sustained cholinergic activity (Reimer et al., 2016); our animals run throughout, and the anchoring state is a sustained variable held across blocks of tens of trials. The timescale fits for the same reason. Neuromodulatory tone varies over tens of seconds to minutes, which is the scale of the blocks we observe, whereas a state propagated synaptically within the entorhinal circuit has no particular reason to vary on that scale — a point independent of the connectivity null, which concerns which pairs share the state rather than how slowly it changes.

We offer this as the septal candidate our data do not exclude rather than one they establish. Pupil diameter indexes a correlate of cholinergic activity and not acetylcholine itself, and nothing here separates cholinergic tone from any other variable covarying with sustained engagement. The direction also runs against the familiar reading in which cholinergic activation accompanies attention: here the code is best anchored, and the animal performs best, when the pupil is narrow. Testing it requires measuring or manipulating cholinergic tone directly, which these recordings cannot do.

A different locus is suggested by what the two gamma bands are likely to be. Gamma rhythms are generated by fast-spiking inhibitory neurons, in loops whose frequency is set by the kinetics of the inhibitory limb, so two bands that move in opposite directions are more naturally two loops than one rhythm of varying amplitude. Our monosynaptic data describe such a loop directly: interneuron-to-grid is the strongest pathway we detect, grid-to-grid the strongest excitatory one, and the inhibitory limb is the slower of the two. The same fast-spiking population supplies the dominant inhibition onto grid cells, carries the speed signal, and generates the rhythms. That offers a reason for these cells to follow the state which does not depend on their coupling to grid cells: on this view they do not report the state so much as constitute it.

The state would then be the balance between a recurrent entorhinal loop and a feedforward sensory one, set by neuromodulatory tone rather than by either circuit, and the polarity is the one we observe. Cholinergic tone favours feedforward input over recurrent transmission, and the anchored state is the constricted-pupil state, which should therefore be the recurrent-dominant one: slow gamma higher, fast gamma lower and less tightly nested in theta. That vision should be down-weighted in the state where performance is best is not paradoxical in this task. When the gain between locomotion and the visual scene is altered, mice follow self-motion rather than vision (Tennant et al., 2018), and on uncued trials the reward zone carries no visual marker at all. The account does not require the two bands to trade against one another exactly, which matters because the per-hertz balance we observe does not survive weighting by bandwidth: modulation of feedforward transmission and of recurrent gain would act on different targets, and need not conserve a fixed amount of power between them.

We state this as a hypothesis rather than a conclusion, because its weakest step is an assignment borrowed from elsewhere. The association of slow and fast gamma with internally and externally guided processing derives from hippocampal recordings, where fast gamma indexes entorhinal input to CA1; that framework cannot be carried into entorhinal cortex unexamined, since there the same band cannot index its own input. The assignment could be earned directly in these recordings rather than assumed: in the sessions where entorhinal cortex, the subicular complex and visual cortex were recorded together, the two bands should differ in which structure they cohere with. Until that is done, the account identifies a locus consistent with our data rather than one our data establish.

We had expected phase precession to decide between the pacemaker and speed-pathway accounts, since they predict opposite outcomes for it. That test is not yet decisive in our hands. Precession is detectable in the expected direction — slopes are negative in 59% of cells (p = 3 × 10⁻⁹) — but at a magnitude far below what the phenomenon should produce, with a circular–linear correlation (Kempter et al., 2012) barely separable from the chance level for the available spike counts, and a minimum detectable state difference several times the size of the entire signal. Both the naive and the field-matched comparisons are null, and neither null is informative. We attribute this to pooling spikes across field traversals, which is close to worst-case in a dataset where field position varies between trials by construction; a per-traversal analysis is the obvious next step, and until it is done we draw no conclusion from precession in either direction.
